# React Todo App

A simple and responsive Todo App built using **React.js** and **Vite**.

## 🚀 Features

- Add new todos
- Add task descriptions
- Edit existing todos
- Update todo status
- Filter todos by status
- Delete todos
- Color-coded status selection
- Responsive design
- Clean and simple user interface

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
